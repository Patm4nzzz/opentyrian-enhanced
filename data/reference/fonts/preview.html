OpenTyrian2000 — Exported fonts

Three sizes extracted from tyrian.shp (sections 0, 1, 2), converted to TTF/WOFF2 with utils/extract_font_ttf.py.

Glyph coverage by size

  • Large (60 glyphs, 12px native) — A-Z, a-z, basic punctuation (! ? . , ; : ' "). No digits, no accents.
  • Small (85 glyphs, 8px native) — all of Large + digits 0-9 + extended punctuation (() {} [] / | \ - + = # $ % *). Still no accents.
  • Tiny (127 glyphs, 5-6px native) — full coverage: Large + Small + all the CP437 accents (é à è ê ë ï î ô ö û ù ç ü ÿ ñ + capitals Ä Å É Ö Ü Ç Ñ).

Recommended fallback stack

For text mixing letters + digits + accents, stack Large/Small on top of Tiny so that the browser falls back to Tiny for the missing glyphs.

Pixel-perfect tip

Sizes that are multiples of the native height (Large: 12, Small: 8, Tiny: 5-6 px) give the sharpest rendering. CSS to turn off anti-aliasing:

.retro-text {
  font-family: "Tyrian Large", "Tyrian Tiny", monospace;
  -webkit-font-smoothing: none;
  -moz-osx-font-smoothing: grayscale;
  font-smooth: never;
  image-rendering: pixelated;
}
