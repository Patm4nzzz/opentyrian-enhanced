OpenTyrian2000 Enhanced - HD (AI) art pack
==========================================

Optional add-on for the "lite" download of the game. It adds the "HD (AI)"
graphics mode: every image enlarged four times in advance by an AI model
trained on pixel art (4x-PixelPerfectV4). The full download already contains
it: you do not need this pack with the full download.

Install
-------
Extract this archive INTO the game folder, the one that contains
OpenTyrian2000-Enhanced.exe (Windows) or OpenTyrian2000-Enhanced.x86_64 (Linux),
so that the "upscaled" folder sits next to the executable:

    OpenTyrian2000-Enhanced/
        OpenTyrian2000-Enhanced.exe   (or .x86_64)
        data/
        upscaled/        <- from this pack
            sprites/  maps/  pics/  manifest.json  sources.sha256

Then start the game and choose Setup > Graphics > Sprites > Remastered
(or press F10, Graphics: HD (AI)).

Use the pack of the SAME release as the game: the images are checked against
the game's own pictures when the pack is built, and a pack from another
release may show wrong frames.

Remove
------
Delete the upscaled folder. The game then offers Original and Sharp pixel art
only; a saved HD (AI) choice is shown and drawn as Original.
