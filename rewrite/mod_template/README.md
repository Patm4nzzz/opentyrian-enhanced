# Mod template

Starting point for a mod for the Godot + Rust rewrite (single format, MODDING.md).

```
my_mod/
  mod.json            ← required ("format_version": 1; see the comments inside)
  README.md           ← shown in the Mods menu (1 KB max)
  levels/ep1_09.json  ← optional: events of one level
  sprites/shots/…png  ← optional: images, referenced by name
```

Step-by-step tutorial: `docs/FIRST_LEVEL_15_MIN.md`. Reference: `MODDING.md`.
