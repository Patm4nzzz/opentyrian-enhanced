# Alien Pack

Retired from the release (October 2026): kept as a reference example, never
loaded by the game nor packaged (`rewrite/mods/README.md`).

Green alien fleet: a biomechanical Gencore II hull and four Tyrian
weapons recolored acid green by the mod's tint (`tint`).

Equipment of a new game: Xeno Vanguard + Alien Vulcan Cannon
(front) + Alien Guided Orbs (rear).

Each object clones an original object (`base`, by its name): the balance
stays that of the original game, only the colors change.
