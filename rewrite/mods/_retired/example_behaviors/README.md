# Example Behaviors

Retired from the release (October 2026): kept as a reference example, never
loaded by the game nor packaged (`rewrite/mods/README.md`).

Example mod for the Godot + Rust rewrite:

- **Helix Driver**: a new front gun, sold everywhere and equipped at the start;
- **zigzag_drone**: a new enemy (zigzag + pursuit + three-shot turret);
- added to the first level of episode 1 (`levels/ep1_09.json`).

Everything is data and referenced by name: no recompilation, no
number to pick. See `MODDING.md` §7 and §8.
