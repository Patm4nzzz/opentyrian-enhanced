# Mods shipped with the rewrite

| Folder | What it adds |
|---|---|
| `alien_ship_pack/` | 8 Hazudra and Zica ships drawn in the original style (the game's VGA palette, dark outline, five banking poses `ship_poses`) |
| `bio_ships_pack/` | 6 bio-organic alien ships (carapaces, membranes, spore sacs), same style and five poses each |
| `alien_weapon_pack/` | 6 Hazudra and Zica weapons (3 front, 3 rear), 11 power levels each, shots and shop icons in the original style |
| `bio_weapons_pack/` | 6 living weapons (3 front, 3 rear: spores, acid, thorns, larvae, pollen, seeds), 11 power levels each |
| `elements_weapon_pack/` | 6 elemental weapons (fire, ice, lightning front; earth, acid, wind rear), 11 power levels each |

Each pack's README gives its balance tables (price, armor, damage per second,
energy) against the original items of the same price, and how its art was made
(`docs/mod-art-pipeline.md`).

All of them ship disabled: **Setup → Mods**, Enter to enable. The five can be
enabled at once:

| Limit (all mods together, MODDING.md §5) | Capacity | Used by the five packs |
|---|---|---|
| Ship slots | 14 | 14 (8 + 6) |
| Ship images (one per PNG, five poses per ship) | 14 ships × 5 poses | 70 (40 + 30) |
| Weapon slots | 20 | 18 (6 + 6 + 6) |
| Shop list of a category | the level's items + 16 mod items | ships 14, front guns 9, rear guns 9 |

`original-names.json`: names of the original enemies and enemy weapons
that a mod can reference (generated, MODDING.md §7.5; preview sheets in
`docs/original-enemies/`, a folder generated by `tyrian-mods catalog --sheets`, not kept in the repository).

`_retired/`: mods removed from the release, kept for reference (never
loaded, never copied into the package; load them by hand with
`tyrian-mods check --mods mods/_retired --enable-all`, or copy one into the user mods folder):

| Folder | Why it is kept |
|---|---|
| `alien_ships/` | 12 ships; its style was not retained and it took 12 of the 14 ship slots |
| `alien_pack/` | worked example of items cloned from an original item (`base`), mod tint (`tint`) and starting equipment (`starter`) |
| `example_nova_weapons/` | worked example of weapons written from scratch: power levels, original sprites referenced by name, the mod's own PNGs, piercing and homing shots |
| `example_behaviors/` | worked example of an enemy weapon and a new enemy with a data-driven behavior, added to a level (MODDING.md §7) |

`alien_pack`, `example_nova_weapons` and `alien_ships` are the one-time
conversion of the C version's mods. The C edition was removed from the
repository (ADR 0132) with its original mods; only
their `mod.json` remain, as a test fixture (`tyrian-mods/tests/fixtures/c-mods`). The
rewrite only reads the single format (`"format_version": 1`, MODDING.md): a
C-version mod is listed as an error, never interpreted.

`mod.schema.json`: JSON schema of the `mod.json` files (referenced by their `"$schema"` key),
checked in CI against these mods by check-jsonschema (MODDING.md §3).

Check every mod without launching the game:

```
cd rewrite
cargo run --release -p tyrian-mods -- check --data ../data --enable-all
```
