## `marketing/godot/`: assets of the Godot + Rust rewrite

All captured from the rewrite itself, at 1280×800 (4× the 320×200 screen),
under `xvfb-run`, by the video path of Godot (`--write-movie`): one movie frame
= one game tick, with the game's own music and sound effects.
